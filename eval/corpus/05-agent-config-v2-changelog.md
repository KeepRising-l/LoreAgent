# LoreAgent 系统运行参数配置更新公告（v2 版 · 2026-10-20）

随着知识库引入多工具并发检索以及超长技术文档（单篇超过 3000 字）分批向量化，2026 年 8 月发布的 v1 基线配置在实际压测与联调中暴露出两类明显瓶颈：复杂查询容易提前撞上步数上限，以及大批量文本一次送往 Embedding 接口时容易触发 504 网关超时。经 2026 年 10 月中旬核查评估，正式发布 **v2 配置参数变更说明**，下列数值自 2026-10-20 起作为系统默认运行参数生效。

## 一、核心参数变更对照表（相对 2026-08 v1 规范）

1. **最大推理步数上限（`max_steps`）**：从 v1 版的 `6` 步上调至 **`10` 步**。
   - 变更原因：在挂载检索工具、计算器、工作区读取等工具后，一个复合问题经常需要「先查询两次文档片段 → 调用计算工具校验数值 → 再次核对引用上下文 → 生成最终回复」，总共 6 步在连续工具场景下过于紧张，经常在第 6 步尚未输出总结时就被 `BUDGET_EXCEEDED` 强行截断。上调至 `10` 步可在控制风险的同时容纳 3～4 轮工具串行推理。
2. **Embedding 单批提交上限（`max_batch_size`）**：从 v1 版的 `32` 条下调至 **`16` 条**。
   - 变更原因：部分第三方 OpenAI 兼容网关或私有部署的向量推理节点对单次 HTTP `/embeddings` 请求的 token 总量或请求体大小有限制。在遇到单段偏长的技术文档时，32 条并发打包一次发送容易超过代理层的 10 秒读超时或触发上游 payload 报错。改为 `max_batch_size = 16` 后，`EmbeddingClient` 会自动将超限切片拆分为多批顺序请求，既兼容严格限流网关（常见上限 10～100 条），又大幅降低了单批失败重试成本。
3. **默认检索向量相似度下限阈值（`minVectorScore`）**：由早期内部实验建议的 `0.35` 下调为 **`0.25`**。
   - 变更原因：中英混排技术问题在部分轻量 Embedding 模型下的绝对余弦相似度普遍偏低（正相关片段往往分布在 `0.26 ~ 0.55` 之间）。如果硬门槛设在 `0.35`，会导致大量有效中文口语问句在未进入 `KeywordSearch` 补充前就被过严阈值误伤或触发误拒答。配合 RRF 双路融合后，将纯阈值门限降为 `0.25` 并结合关键词命中情况综合判定，更加稳健。

## 二、向后兼容与配置覆盖方式

本次参数调整均通过构造器默认值与配置属性提供（例如 `lore.embedding.max-batch-size: 16`），如果运维侧通过环境变量或 `application-local.yml` 显式设置了覆盖项，仍以环境变量优先（Spring Boot 配置优先级：动态属性 > 操作系统环境变量 > `application-local.yml` > `application.yml`）。

需要注意，当知识库里同时存在 `2026-08-10` 发布的旧版 v1 文档和 `2026-10-20` 发布的新版 v2 文档时，基础 RRF 检索可能将两份包含相同关键词 `max_steps` 与 `max_batch_size` 的文档同时召回。因此在后续版本规划中，检索管线会通过日期过滤与矛盾检测把此类新旧文档参数冲突显式标出，提示用户优先采信更新日期较近的 `2026-10-20` 规范。

## 三、落库与监控日志规范补充

配合本次变更，所有问答运行轨迹需通过 `run_trace` 表留痕，必须记录：`conversation_id`（外键级联删除 `on delete cascade`）、`request_id`、`user_id`、`query`、当次召回片段摘要 `retrieved_chunks jsonb`（包含 `documentId`、`chunkId`、`score`）、是否触发向量降级 `degraded` 标志、模型结束原因 `finish_reason` 与创建时间。任何时刻严禁将 API Key、Bearer Token 或完整原文直接打进日志正文，日志一律遵守 `key=value` 结构化输出约定，便于后续评测与故障回溯。

## 四、上线验证与回滚预案

为保证配置切换可验证、可回退，本次 v2 参数生效后需在集成测试库 `loreagent_test` 中同步完成两项基线检查：第一，针对包含 20 个以上技术片段的长文档验证 `EmbeddingClient` 在 `max_batch_size = 16` 条件下的自动拆批提交行为，确认每批请求数组长度严格不超过 16 且最终拼接向量顺序与原始片段 `chunk_index` 一一对应；第二，针对带有 `2026-08-10` 与 `2026-10-20` 冲突阈值的问答对保留评测样例，供后续引入规则重排与冲突检测器后量化对比 Top-3 与 MRR 指标变化。如遇个别自部署兼容网关不支持较小的批大小或需要临时放宽限制，仅需调整 `LORE_EMBEDDING_MAX_BATCH_SIZE` 环境变量即可即时热切换，无需修改并重新打包服务端代码。
